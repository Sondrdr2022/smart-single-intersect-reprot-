\chapter{Chi tiết triển khai}

\section{Mục tiêu chương}
Chương này tập trung vào cách triển khai hệ thống APC–RL ở mức thực hành: cài đặt, cấu hình, tổ chức mã, các điểm tích hợp và checklist triển khai. Các chi tiết thuật toán và mã nguồn đã được trình bày ở:
\begin{itemize}
    \item APC và quản lý ưu tiên: Chương~5
    \item RL agent (Q-learning): Chương~6
    \item Chiến lược điều khiển lai: Chương~7
    \item Lưu trữ và đồng bộ dữ liệu (Supabase, Q-table): Chương~9
\end{itemize}

\section{Cài đặt và cấu hình hệ thống (tóm tắt)}
\begin{enumerate}
    \item Python 3.8+ và thư viện nền: NumPy, Pandas, Matplotlib, TraCI, Supabase client.
    \item Cài SUMO và cấu hình \texttt{SUMO\_HOME}. Thiết kế topology, demand và logic đèn bằng NETEDIT; tạo \texttt{.sumocfg}.
    \item Khởi tạo Supabase (URL, API key) và cấu hình trong \texttt{config.py}.
    \item Kiểm thử nhanh: chạy mô phỏng SUMO với tệp \texttt{.sumocfg}, đảm bảo TraCI kết nối và dashboard hiển thị được trạng thái.
\end{enumerate}
Gợi ý: giữ lệnh cài đặt chi tiết và script khởi chạy trong Phụ lục hoặc README của mã nguồn để tránh lặp.

\section{Tham số cấu hình chính}
Các tham số cốt lõi (định nghĩa cụ thể xem Chương~5 và Chương~6):
\begin{itemize}
    \item \texttt{min\_green}, \texttt{max\_green}: giới hạn an toàn/công bằng cho pha xanh.
    \item \texttt{alpha}, \texttt{r\_base}, \texttt{r\_adjust}: điều chỉnh động thời lượng pha dựa trên reward (Chương~5).
    \item \texttt{weights} cho reward [density, speed, wait, queue] và cơ chế cập nhật (Chương~6).
    \item Ngưỡng ưu tiên: \texttt{protected\_left\_min\_queue}, \texttt{severe\_congestion\_threshold}.
    \item \texttt{pending\_requests}: hàng đợi ưu tiên (emergency, starvation, congestion, normal) (Chương~5,7).
    \item Tham số đồng bộ dữ liệu: batch size, interval, retry, RLS (Chương~9).
\end{itemize}

\section{Cấu trúc module triển khai}
\begin{itemize}
    \item \textbf{UniversalSmartTrafficController}: Điều phối trung tâm một nút giao; gọi APC, RL, và ghi log (Chương~7).
    \item \textbf{AdaptivePhaseController (APC)}: Điều chỉnh pha động, chèn vàng, bảo vệ rẽ trái, hàng đợi ưu tiên (Chương~5).
    \item \textbf{EnhancedQLearningAgent}: Q-learning, epsilon-greedy, optimistic init, valid action mask (Chương~6).
    \item \textbf{PatchedAsyncSupabaseWriter}: Ghi trạng thái/sự kiện theo lô, retry, write-behind (Chương~9).
    \item \textbf{SmartIntersectionTrafficDisplay}: Dashboard trực quan thời gian thực (Chương~14).
\end{itemize}

\section{Luồng điều khiển (triển khai)}
Mỗi bước mô phỏng thực hiện chu trình khép kín:
\begin{enumerate}
    \item TraCI đọc trạng thái (xe, làn, đèn) từ SUMO.
    \item APC kiểm tra điều kiện ưu tiên: emergency, starvation, congestion, protected left (Chương~5).
    \item Nếu không có ưu tiên, RL agent chọn pha (Chương~6); nếu có, rule-based override (Chương~7).
    \item Thực thi chuyển pha an toàn: kẹp chỉ số pha, chèn vàng, enforce \texttt{min\_green} (Chương~5).
    \item Ghi reward, sự kiện, trạng thái lên Supabase theo batch (Chương~9); dashboard cập nhật (Chương~14).
\end{enumerate}

\section{Điểm tích hợp và thực hành tốt}
\subsection{TraCI và SUMO}
\begin{itemize}
    \item Ưu tiên subscription để giảm overhead; dùng cache logic pha TTL ngắn (Chương~5).
    \item Rate-limit thay đổi logic/phases để tránh flicker và xung đột.
\end{itemize}

\subsection{Supabase và lưu trữ}
\begin{itemize}
    \item Ghi theo lô; retry với exponential backoff; chuyển sang lưu cục bộ khi offline (Chương~9).
    \item Dùng JSONB + GIN index; RLS cho an toàn truy cập.
\end{itemize}

\subsection{Dashboard và quan sát}
\begin{itemize}
    \item Theo dõi hàng chờ, thời gian chờ, trạng thái pha, sự kiện ưu tiên.
    \item Lưu lại để phân tích hậu kỳ, so sánh kịch bản (Chương~14).
\end{itemize}

\section{Checklist triển khai}
\begin{itemize}
    \item SUMO/NETEDIT: Topology, logic đèn, demand hợp lệ; \texttt{.sumocfg} liên kết đúng.
    \item TraCI kết nối ổn định; subscription biến cần thiết.
    \item Tham số \texttt{min\_green}/\texttt{max\_green}, ngưỡng ưu tiên được hiệu chỉnh theo kịch bản.
    \item Supabase: bảng, index, policy RLS; writer bật, batch/interval phù hợp.
    \item RL agent: epsilon/weights/hyperparameters khởi tạo đúng; Q-table load/save hoạt động (Chương~6,9).
    \item Dashboard: hiển thị realtime; log sự kiện đủ để phân tích.
\end{itemize}
